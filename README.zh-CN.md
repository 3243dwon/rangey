# 🏌️ rangey — 中文使用说明

> 把记分卡给 Claude 看,它告诉你杆数到底丢在哪,再给你一套有科学依据的练习去补——还帮你记录有没有进步。

免费、开源。不用下 App、不用开会员,跑在你已经在用的 Claude 里。
（完整英文文档见 [README](README.md)。）

---

## 这是什么

rangey 是一个 Claude 技能(skill)。给它一张记分卡照片(或几个数据),它会:

1. 算出一张「**你的杆数都丢在哪**」的拆解(类 strokes gained 的近似);
2. 点名你**最大的那个漏洞**(推杆 / 进攻 / 短杆 / 开球);
3. 按运动学习的研究,给你一套**针对这个漏洞**的练习,以一个能记录的「压力测试分数」收尾;
4. 下次再读,看漏洞有没有变小、分数有没有降。

它**不是**挥杆教学、伤病建议,也不是又一个动作库。它管的是「**怎么练**」,不诊断你的动作。

---

## 三种用法

### ① 零安装试用(最快,谁都能试)
不用装、不用付费:打开任意一个 Claude 对话,把 [`SKILL.md`](SKILL.md) 的内容整段贴进去,附一张记分卡照片,说一句「按这个告诉我该练什么」。30 秒就能看到效果。

### ② Claude.ai 网页 / App(大多数人)
1. **设置 → Capabilities**:打开 **Code Execution** 和 **File Creation**(不开技能跑不起来);
2. **设置 → Skills**:把 rangey 文件夹打包成 **`.zip`** 上传——注意让 `SKILL.md` 在压缩包**最外层**(GitHub 自动下载的 zip 会多套一层 `rangey-main/`,重新压一下);
3. 直接聊:「*我有 30 分钟在练习场,这是我的记分卡* 📷」——它会自动触发。

> 需要付费套餐(Pro / Max / Team / Enterprise)。没有的话用上面的「零安装试用」。

### ③ Claude Code 命令行(开发者)
把仓库放进个人技能目录,让 `SKILL.md` 正好在第一层:
```bash
git clone https://github.com/3243dwon/rangey ~/.claude/skills/rangey
```
(常见错误:套太深。路径必须是 `~/.claude/skills/rangey/SKILL.md`。)
然后**新开一个会话**就会自动识别,直接对话即可。

## 一次完整对话长这样

> **你:** 我有 30 分钟在练习场,这是我上一轮的记分卡 📷
> (或直接说:打了 92 杆、37 推、上球道 7/14、上果岭 6 个、1 个罚杆)
>
> **rangey:** 先给你一张「杆数都丢在哪」的拆解 → 🎯 **最大漏洞:推杆**(约丢 3 杆) → 给你一套 30 分钟推杆练习,以「4 英尺连进 10 个、进不了重来」的压力测试收尾 → 让你记下这个分数。

练完、下一轮再来,它对比趋势,自动调难度:进步了 → 加难度;卡住了 → 换练法或更随机。

## 不想用对话?脚本能单独跑(零依赖,连模型都不用)

```bash
# 记一轮成绩,直接看漏洞拆解
python scripts/round_log.py add --level mid --score 92 --putts 37 \
    --fir 7/14 --gir 6 --updowns 3/12 --penalties 1

# 记一次练习的压力测试分数,看趋势
python scripts/practice_log.py add --focus putting --score 7
python scripts/practice_log.py show
```

参数说明:`--level` 段位(beginner / mid / low / scratch)、`--putts` 总推杆、`--fir` 上球道(命中/球道洞数)、`--gir` 标准杆上果岭(共 18)、`--updowns` 救球(成功/机会)、`--penalties` 罚杆数。只需要 Python 3。

## 诚实说明

- 那张「丢杆拆解」是**近似**,不是逐杆的 strokes gained(真要那个得有测距仪 / 传感器)。它够帮你**找出最大的漏洞、安排一次练习**,不是用来对标职业数据表。
- 它是**练习指导**,不是挥杆教学或医疗建议;也刻意**质量 > 数量**——成桶猛抡全挥杆是球友受伤的主要原因。
- 自报数据有噪声没关系,它看的是你最突出的漏洞和几场下来的趋势,不是小数点精度。
